## 데이터 분석팀이 로컬 서버(온프레미스)에서 클라우드로 분석 환경을 이전하려 합니다. 

### 0. 온프레미스와 클라우드 비교

| 비교 항목 | 온프레미스 (로컬/자체 서버) | 클라우드 (AWS, GCP 등) |
| :--- | :--- | :--- |
| 인프라 형태 | 물리적 서버 직접 구축 | 인터넷을 통해 빌려 쓰는 가상 인프라 |
| 비용 구조 | 서버 구매, 설치 | 사용한 만큼만 결제 |
| 확장성 | 서버 부품 구매·세팅에 수 주~수 개월 소요 | 클릭 몇 번이나 코드로 몇 분 만에 증설/축소 |
| 유지 관리 | 하드웨어 고장, OS 패치, 백업을 직접 관리 | 인프라 관리는 클라우드 기업이 전담 |
| 보안/통제 | 사내망 안에서 데이터 완벽 통제 가능 | 클라우드 보안 정책 및 권한(IAM) 관리 필요 |

### 1. 이 결정의 어떤 장점이 가장 큰 이유가 될 것 같나요? 
- 필요할 때만 성능을 늘려 쓸 수 있음.
- 서버 관리에 시간을 뺏기지 않고 분석에 집중할 수 있음.
- 팀원들과 같은 환경에서 쉽게 협업할 수 있음.

### 2. 반대로 클라우드 전환을 고민하게 만드는 우려 사항은 무엇이 있을까요?
- 실수하면 예상치 못한 비용 폭탄이 나올 수 있음.
- 데이터 보안과 규정 준수가 까다로움.
- 처음 옮길 때 드는 시간과 학습 부담이 큼.

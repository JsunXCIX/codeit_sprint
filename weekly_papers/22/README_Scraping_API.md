# 웹 스크래핑 vs API 호출

## 1. 핵심 차이점

| 구분 | API 호출 | 웹 스크래핑 |
| :--- | :--- | :--- |
| **방식** | 정식 제공 엔드포인트로 데이터 요청 | HTML 전체를 긁어와 필요한 데이터 파싱 |
| **포맷** | JSON, XML (정제된 데이터) | HTML, CSS (비구조화 데이터) |
| **속도/효율** | 필요한 데이터만 수신해 **빠름** | 불필요한 태그·요소 포함되어 **상대적으로 느림** |
| **안정성** | UI 변경과 무관하게 **높음** | 웹사이트 HTML 구조 변경 시 **코드 깨짐** |
| **제재 위험** | API Key 기반으로 **안전** | 과도한 요청 시 **IP 차단** |

<br>

## 2. 상황별 선택 기준

### API 호출
- **공식 API가 존재하는 경우** (최우선 선택)
- 주식, 날씨 등 **실시간·고정밀 데이터**가 필요할 때
- UI 변경에도 영향 없는 **안정적인 데이터 수집**이 필요할 때

### 웹 스크래핑
- **공식 API가 없을 때**
- API 호출 제한이 심하거나 비용이 부담될 때
- 화면에 보이는 그대로의 **웹 페이지 정보 모니터링**이 필요할 때

---

>  **한 줄 요약:** API가 제공된다면 우선 사용하고, API가 없거나 제약이 있을 때 웹 스크래핑을 차선책으로 선택.

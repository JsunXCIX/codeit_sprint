## Q1. PCA와 LDA는 둘 다 차원 축소 기법인데, 어떤 차이가 있나요? 어떤 상황에서 각각을 선택하겠나요?

### 핵심 차이점
PCA(주성분 분석)와 LDA(선형 판별 분석)는 고차원 데이터의 변수를 줄여 연산 효율성을 높이고 시각화를 돕는 대표적인 차원 축소 기법임. 그러나 두 기법은 정답의 활용 여부와 축소의 목적에서 차이가 있음.

- PCA (주성분 분석 - 비지도학습):
    - 원리: 데이터의 레이블을 고려하지 않고, 데이터 전체의 분산이 가장 큰 방향의 축을 찾아 투영함.
    - 목적: 원래 데이터가 가지고 있는 전체적인 고유한 정보 구조와 형태를 손실 없이 최대한 보존.
- LDA (선형 판별 분석 - 지도학습):
    - 원리: 데이터의 레이블을 반드시 활용하며, 클래스 간 분산은 최대화하고 클래스 내 분산은 최소화하는 축을 찾아 투영함.
    - 목적: 서로 다른 클래스의 데이터들이 공간상에서 가장 뚜렷하게 구별되도록 분류 경계의 변별력을 극대화.

### 상황별 선택 기준

- PCA를 선택하는 상황:
    - 데이터에 정답 레이블이 없는 EDA나 클러스터링 전처리 단계일 때
    - 고차원 이미지나 센서 데이터 등에서 핵심적인 변동 트렌드만 남겨 머신러닝 모델의 과적합을 방지하고 노이즈를 제거하고 싶을 때
- LDA를 선택하는 상황:
    - 최종 예측 목적이 분류 성능 향상이며, 정답 레이블이 명확하게 주어져 있을 때
    - 분류 모델 학습 직전 단계에서 클래스 간 경계면을 뚜렷하게 만들어 예측 정확도를 직접적으로 끌어올릴 수 있다고 판단될 때

## Q2. TF-IDF는 단순 단어 빈도(TF)와 어떻게 다른가요? TF-IDF가 텍스트 분석에서 더 유용한 이유를 예시와 함께 설명해 보세요.

### 개념적 차이점
- TF: 특정 문서 내부에서 해당 단어가 등장하는 절대적인 횟수. "문서 내에 자주 나오는 단어가 핵심 키워드일 것"이라는 가정을 따름.
- TF-IDF: 단순 단어 빈도(TF)에 역문서 빈도(IDF)를 곱한 값. "특정 문서 내에서 자주 등장하면서도, 다른 문서들 전체에서는 흔하게 나오지 않는 단어가 해당 문서의 진정한 핵심 키워드다"라는 가정을 바탕으로 작동함.

### TF-IDF가 더 유용한 이유와 실무 예시 (낚시성 기사 탐지)
단순 TF 방식은 모든 문서에 공통으로 자주 나오는 조사나 범용 단어가 가장 중요한 단어로 집계되는 심각한 왜곡이 발생함. 특히 '데이터와 AI를 이용한 낚시성 기사 탐지' 모델을 구축할 때, 제목과 본문의 키워드 연관성을 분석하기 위해 TF 방식을 쓰면 모델의 성능이 크게 떨어짐. 낚시성 기사들은 클릭을 유도하기 위해 자극적이지만 알맹이 없는 범용 단어를 도배하기 때문임.

- '낚시성 기사 탐지' 기반의 비교 예시:
    - 어떤 연예 뉴스 낚시성 기사 제목이 "[충격] 톱스타 A군, 결국 눈물 흘린 진짜 이유 알고 보니..." 이고, 본문에는 전혀 다른 뻔한 일상 내용이 들어있다고 가정.
    - TF 방식 적용 시: 기사 제목과 본문에서 '충격'(3회), '결국'(4회), '진짜'(3회), '이유'(3회) 같은 단어들이 빈도가 높게 집계되므로, TF는 이 단어들을 기사의 핵심 키워드로 판단함. 하지만 이 단어들은 수많은 다른 낚시성 기사나 일반 기사에도 매일같이 남발되는 단어이므로 기사의 진짜 '주제'나 '낚시성 여부'를 판별하는 척도가 되지 못함.
    - TF-IDF 방식 적용 시: '충격', '결국', '진짜' 같은 단어들은 전체 기사 코퍼스(수만 개의 문서) 중 수많은 기사에 광범위하게 등장하므로 IDF 값이 바닥으로 떨어져 최종 점수가 대폭 깎입니다. 반면, 본문에 아주 가끔 언급된 실제 사건의 고유 명사(예: 특정 프로그램 이름, 고유 브랜드 등)는 전체 문서에서 희소하게 등장하므로 IDF 가중치가 높게 책정됨.
    - 결과: TF-IDF를 활용하면 제목에 나타난 '낚시용 자극적 단어'의 점수는 낮추고, 본문 핵심 소재의 점수를 살릴 수 있습니다. 이를 통해 "제목의 고점수 키워드와 본문의 고점수 키워드가 서로 일치하지 않는다"는 시그널을 AI 모델에 전달할 수 있게 되며, 결론적으로 낚시성 기사를 훨씬 정교하게 탐지해 낼 수 있음.

## Q3. K-Means와 DBSCAN은 어떤 차이가 있나요? DBSCAN이 K-Means보다 유리한 상황을 예시와 함께 설명해 보세요.

### 핵심 차이점
두 알고리즘은 대표적인 비지도 기반 클러스터링 기법이지만, 군집을 정의하고 묶어나가는 수학적 메커니즘에서 뚜렷한 차이를 보임.

| 구분 | K-Means | DBSCAN |
| :--- | :--- | :--- |
| **군집 형성 방식** | **중심점(Centroid) 기반** | **밀도(Density) 기반** |
| **군집 수 ($K$) 지정** | **사용자가 미리 명시해야 함** | 미리 지정할 필요 없이 자동 결정됨 |
| **핵심 하이퍼파라미터**| 군집 개수 ($K$) | 반경 ($\epsilon$, epsilon), 최소 샘플 수 ($MinPts$) |
| **이상치(Outlier) 처리** | 아웃라이어도 억지로 가장 가까운 군집에 포함시킴 | 어떤 군집에도 속하지 않는 **'노이즈'로 깔끔하게 분리** |
| **적합한 데이터 형태** | 원형이나 볼록한 분포 | 기하학적이고 연속적인 밀도를 가진 복잡한 분포 |

### DBSCAN이 더 유리한 상황과 예시

- 상황 1: 복잡하고 비선형적인 독특한 형태의 데이터 분포
    - K-Means는 중심점으로부터 거리가 일정한 원형 구조로만 구역을 나눔. 만약 데이터가 초승달 모양 두 개가 맞물려 있거나, 큰 원 안에 작은 원이 들어있는 동심원 구조일 때 K-Means는 공간을 직선으로 쪼개기 때문에 군집을 완전히 엉망으로 분리함.
    - 반면 DBSCAN은 점과 점 사이의 거리가 반경 내에 촘촘하게 연결되어 있다면 밀도를 따라 흐르듯이 군집을 확장하므로, 아무리 기하학적으로 꼬여 있는 형태라도 완벽하게 독자적인 군집으로 잡아냄.
- 상황 2: 이상치가 많아 정제가 필요한 실무 데이터 분석
    - K-Means는 모든 데이터를 단 하나도 빠짐없이 특정 군집에 강제로 포함시켜야 하므로, 극단적인 아웃라이어가 존재하면 군집의 중심점이 왜곡되는 치명적인 단점이 있음.
    - 예시 (신용카드 이상 거래 및 부정 사용 탐지): 정상 고객들의 대다수 결제 패턴 데이터는 특정 영역에 빽빽한 밀도로 모여 있고, 사기 거래 데이터는 정상 범주에서 멀리 떨어진 공간에 드문드문 발생함. K-Means를 쓰면 이 사기 데이터들까지 억지로 정상 군집에 포함되어 패턴이 뭉개짐. 반면 DBSCAN을 적용하면 빽빽한 정상 데이터들만 군집화하고, 멀리 떨어진 사기 데이터들은 최소 밀도 요건을 충족하지 못하는 이상치로 완벽하게 격리해 내어 이상치 탐지 효율을 극대화할 수 있음.

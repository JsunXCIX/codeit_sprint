## Q1. 훈련 데이터 정확도(95%) 대비 테스트 데이터 정확도(65%) 저하 현상
### 1) 현상: 과적합 (Overfitting)
* 개념: 모델이 훈련 데이터에 지나치게 학습되어서, 새로운 데이터에 대한 예측 능력이 떨어지는 현상.
* 비유: 익숙한 환경이나 친한 친구들의 성향에만 익숙해진 나머지, 완전히 새로운 환경이나 낯선 사람들을 만났을 때 유연하게 적응하지 못하는 상태와 유사하다고 생각함.

### 2) 발생 원인
* 모델의 복잡함: 데이터의 양이나 특성 수에 비해 모델의 파라미터가 너무 많아 데이터 본질의 패턴이 아닌 '무작위 노이즈'까지 통째로 암기해 버린 경우.
* 데이터의 다양성 및 양적 부족: 훈련 데이터셋이 현실 세계의 다양한 케이스를 대변하지 못해 특정 편향된 데이터에만 최적화되었을 때 발생함.

### 3) 해결 방안
* 데이터 증강 및 전처리: 데이터의 절대적인 양을 늘리고, 불필요한 노이즈를 정제하여 현실 세계의 다양한 도메인을 반영.
* 모델 복잡도 완화: 가중치의 개수를 줄이거나 의사결정나무의 경우 가지치기를 통해 모델을 더 단순화.
* 규제 적용: 손실 함수에 패널티를 부여하는 L1(Lasso), L2(Ridge) 규제를 통해 모델의 특정 파라미터가 지나치게 비대해지는 것을 방지.
* 교차 검증 활용: 데이터를 여러 개의 폴드로 나누어 검증함으로써 특정 훈련 데이터셋에만 과도하게 종속되는 것을 모니터링.

## Q2. 회귀 모델 평가 지표: MSE vs MAE 선택 기준
### 1) MSE (Mean Squared Error, 평균 제곱 오차)
* 수식: $MSE = \frac{1}{n} \sum_{i=1}^{n} (y_i - \hat{y}_i)^2$
* 특징: 오차를 제곱하여 평균을 구하므로, 오차가 커질수록 모델이 받는 패널티가 기하급수적으로 증가함. 또한, 수학적으로 미분이 가능하여 경사하강법 기반의 모델 최적화에 유리함.
* 유리한 상황: 예측값이 실제값과 큰 차이를 보이는 오차를 잡아내고 방지해야 할 때 위력을 발휘함. (예: 시스템 치명타를 주는 제조 공정 결함 예측, 금융 리스크 관리 등)

### 2) MAE (Mean Absolute Error, 평균 절대 오차)
* 수식: $MAE = \frac{1}{n} \sum_{i=1}^{n} |y_i - \hat{y}_i|$
* 특징: 오차의 절대값을 취해 평균을 구하므로, 모든 오차가 크기에 비례하여 선형적으로 반영됨. 음수 영역을 없애면서 직관적인 오차의 크기를 엔드유저에게 직관적으로 보여주기 좋음.
* 유리한 상황: 데이터 자체에 노이즈나 이상치가 빈번하게 포함되어 있으나, 이를 무시하고 전반적인 모델의 평균적인 흐름과 강건함을 확보하고 싶을 때 유리함. (예: 일반적인 부동산 시세 예측 등)

## Q3. 분류 모델에서 Accuracy(정확도)의 한계와 대체 지표
### 1) 정확도(Accuracy)의 치명적인 한계 상황: 데이터 불균형
* 상황 예시 (암 환자 판별): 전체 검사 대상자 중 99%가 정상인이고 단 1%만이 실제 암 환자인 데이터셋이 있다고 가정. 만약 모델이 아무런 학습도 하지 않고 모든 사람을 무조건 정상이라고만 예측해도, 이 모델의 정확도는 99%가 됨.
* 문제점: 수치상으로는 완벽해 보이지만, 정작 가장 중요한 1%의 암 환자는 단 한 명도 찾아내지 못해 환자의 생명을 위협하는 치명적인 결과를 초래함. 즉, 클래스 비율이 붕괴된 불균형 데이터에서는 정확도가 모델의 실제 성능을 철저히 왜곡함.

### 2) 불균형 데이터셋을 위한 대체 평가지표
정확도의 맹점을 극복하기 위해 오차 행렬을 기반으로 한 다음 지표들을 복합적으로 활용해야 함.

* 재현율: 실제 암 환자인 사람들 중, 모델이 실제로 '암 환자'라고 올바르게 적출해 낸 비율.
    * 중요성: 암 진단, 금융 사기 적발처럼 실제 양성 사례를 놓치면 사회적 비용이나 위험이 극도로 커지는 도메인에서 가장 최우선으로 극대화해야 하는 핵심 지표.
* 정밀도: 모델이 '암 환자'라고 예측한 대상자들 중에서, 실제로 진짜 암 환자였던 비율.
    * 중요성: 일반 메일을 스팸으로 오인하여 격리하면 안 되는 '스팸 메일 분류'처럼, False Positive를 줄이는 것이 치명적일 때 주로 사용됨.
* F1-Score: 정밀도와 재현율의 조화 평균 값.
    * 중요성: 두 지표는 서로 트레이드오프 관계에 있기 때문에, 한쪽 지표로 편향되지 않고 두 성능이 균형 있게 발달했는지 불균형 데이터셋에서 모델의 종합적인 성능을 검증하는 글로벌 표준 지표로 활용됨.

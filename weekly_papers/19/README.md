# 편의점 매출 데이터를 분석했더니 매주 금·토에 매출이 급증하는 패턴이 보입니다. 이를 시계열 관점에서 어떻게 설명하겠나요? 이 패턴을 예측 모델에 반영하려면 어떻게 해야 할까요?

### 시계열 관점에서의 해석
> 시계열 데이터의 구성 요소로는 추세, 계절성 주기성, 잔차 등이 있음.
> 위 패턴은 금, 토 마다 매출 급증이 반복하는 계절성에 해당하고 주간마다 반복하니 주간 계절성이라 볼 수 있음.
> 7일을 주기로 반복되는 패턴인 것으로 보아 주말을 앞둔 금요일과 다음날이 쉬는 날인 토요일에 유동 인구가 늘어나고 소비 심리가 살아나는 것으로 보임.

### 예측 모델 반영 방법
#### SARIMA (처음 생각한 방법)
> 위 패턴에 대한 한 문장의 설명을 보고 가장 먼저 떠오른 방법은 SARIMA 방식임.
> 시간에 흐름에 따른 편의점 매출액을 보여주는 패턴이기에 단변량 시계열이고, 과거의 매출 데이터만을 가지고 미래의 매출을 예측하는 간단한 방법이라고 생각함.
> 또한 계절성 주기가 7일로 명확한 수가 있기에 모델링하기에 간편하다고 생각함.
> 하지만, 다른 변수를 생각하지 못하고 과거 매출 데이터만으로 판단한다는 점에서 유연성이 약간 떨어진다고 생각함.

#### Prophet (SARIMA의 단점을 고려한 방법)
> SARIMA 모델의 한계를 극복하기 위해, 매출에 열향을 주는 외부 변수들을 함께 학습시킬 수 있는 방법이 필요함.
> Prophet을 사용하면 7일 주기로 반복하는 계절성을 챙김과 동시에, 공휴일이나 특정 사건같은 외부 변수들을 유연하게 추가할 수 있음.
> 또한, 모델 내부적으로 weekly_seasonality=True 설정을 통해 금, 토에 발생하는 요일 효과를 별도의 복잡한 인코딩 없이 자동으로 안정적이게 학습할 수 있다는 장점이 있음.
> 더 나아가 날씨, 인근 스포츠 경기 일정, 혹은 대규모 프로모션 여부 등 매출의 변동 폭을 늘리는 외부 변수들을 추가적인 회귀 성분으로 손쉽게 결합할 수 있음.
> 결과적으로, 7일 주기의 주간 패턴은 Prophet의 계절성 기능으로 잡아내고, 갑작스러운 매출 피크나 유동 인구 변화는 외부 변수 주입을 통해 보완함으로써 예측 모델의 유연성과 정확도를 동시에 높일 수 있음.
